Explicit `requireAuth: true` and Sindi use the required SDK wrapper. The backend still determines authorization by its existing router mounts; no endpoint was moved.

The API keeps its existing five-second default deadline across headers/body/auth waits and preserves JSON/error status. Sindi keeps web fetch versus Expo fetch explicitly selected by platform, raw response streaming, caller abort and its exact consent classifier. The SDK prevents caller bearer overrides/foreign origins and does not replay multipart or stream uploads. No local token cache, token getter, refresh handler or bearer header remains in these app helpers.

A real HTTP RED proved the old helper discarded message/deleted/serverTime.
