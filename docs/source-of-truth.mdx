# Source of truth

One authority per domain. This page exists because the most expensive class of
bug in a system like this is not a wrong answer — it is **two modules that both
believe they own something**, disagreeing quietly for months.

Re-derive the table list rather than trusting the counts below:

```bash
perl -0777 -ne 'while (/pgTable\(\s*'"'"'([a-z_]+)'"'"'/gs) { print "$1\n" }' \
  packages/backend/db/schema/*.ts | sort -u
```

Use a multiline parser. `grep -E "pgTable\(\s*'"` returns **zero** on this schema
because the table name sits on the following line and `\s` does not cross a
newline — and zero reads exactly like a clean answer. Measured on this branch: 61
tables across 21 schema files.

## Authorities outside this repository

| Fact | Owner | Consequence |
|---|---|---|
| Who a person is | Oxy (`@oxyhq/core`, `@oxyhq/services`) | No user table, no passwords, no local auth. The linked client owns token refresh; never add a manual `Authorization` header |
| Subscription and payment state | Stripe | Homiio caches entitlements in `billing`; Stripe's webhook is what moves them |
| Image bytes | S3 (`AWS_S3_BUCKET`), or the local store in development | `images` holds metadata and keys, not bytes |
| Infrastructure, secrets, task definitions | `oxy-infra` (`terraform-uswest2`) | A secret added to a task definition must be added to `deploy-aws.yml`'s explicit sync allowlist in the same change, or it is never synced |
| Community moderation decisions | `@oxyhq/crowdsource` | Homiio records outcomes and enforces them; it does not adjudicate |
| Points of interest | OpenStreetMap / Overpass | Cached in `place_pois` with a deadline; a miss is re-fetched |
| Rendering a price, a date, a unit | `@homiio/shared-types` `format/` | A price is never assembled by string concatenation and a currency is never hardcoded |

## The rules these encode

1. **One authority per fact.** If two modules can both write something, one of
   them is wrong. Find the chokepoint before adding a write path.
2. **A serializer is a boundary, not a convenience.** `propertySerializer`,
   `leaseSerializer`, `reviewSerializer`, `addressSerializer` and
   `conversationSerializer` decide what leaves the server. Assembling a DTO in a
   controller creates a second, undocumented wire shape.
3. **The owner comes from the session.** Never from a body field, never from a
   query parameter, on any write.
4. **Ownership is enforced in the query.** Filtering by owner in the repository
   makes a non-owner get a 404 rather than a 403 — a 403 confirms the row exists.
5. **Place names are ids.** `country_id`, `region_id`, `city_id`,
   `neighborhood_id`. Never a copied string on another entity.
6. **A precision is applied on the way out.** One stored value, published at
   whatever precision the audience is entitled to. Never a second, coarser stored
   copy. See [ADR 0003](./adr/0003-privacy-verification-publication).
7. **Reviews and history attach to the place, not the advert.** A listing expires;
   a building does not. See [ADR 0001](./adr/0001-canonical-housing-graph) and the
   [Glossary](./glossary).

## Where a second authority nearly appeared

Worth recording, because each was found rather than avoided, and the shape
repeats:

- **A read path and a write path on different stores.** During the PostgreSQL
  migration, listing reads moved before listing writes, so Postgres held a
  point-in-time copy while the old store kept moving. Reads went stale silently —
  no error, no failing test. Both halves are on PostgreSQL now, and the general
  rule stands: never add a read against a table whose write path you have not
  checked.
- **An analytics query filtering on a field the schema did not declare.** It
  matched nothing, so every figure was `0` for as long as it existed, and a zero
  looks like a quiet market rather than a bug. Whenever a count is suspiciously
  round, check the column name against the schema.
- **A "fallback" payload of invented figures** when an optional upstream service
  was absent. It made the screen render, and it described nothing. Metrics with
  no backing data are `0` now.
- **An expiry deadline that meant two different things.** One column expires a
  share *link*; another expires a cached *advert*. Treating them uniformly would
  have deleted people's conversations. `EXPIRY_COLUMNS_THAT_MUST_NOT_DELETE`
  exists as data so a later tidy-up cannot make that mistake.
